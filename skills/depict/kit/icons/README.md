# Icons

The board draws icons from Lucide 1.57.0 (https://lucide.dev), 2154 icons on a 24 unit grid, all made of strokes, under the ISC license; the icons Lucide derives from Feather are under the MIT license. Both licenses are in `LICENSE`. `tools/icons.mjs` converts the set; an icon's name is its Lucide name (`cpu`, `database`, `users`, `lightbulb`).
