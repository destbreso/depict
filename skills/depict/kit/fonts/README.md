# Handwriting

The board writes with single-stroke fonts, whose glyphs are polylines in pen order. Both come from Evil Mad Scientist's EMS fonts (https://gitlab.com/oskay/svg-fonts), converted by `tools/fonts.mjs`. They are under the SIL Open Font License 1.1 (`OFL.txt`); the converted files stay under it.

- **print**: EMS Tech, created by Sheldon B. Michaels, SVG font conversion by Windell H. Oskay; a derivative of Architects Daughter by Kimberly Geswein, Kimberly Geswein Fonts. SIL Open Font License 1.1. 216 glyphs.
- **marker**: EMS Casual Hand, created by Sheldon B. Michaels, SVG font conversion by Windell H. Oskay; a derivative of Covered By Your Grace by Kimberly Geswein, Kimberly Geswein Fonts. SIL Open Font License 1.1. 216 glyphs.
